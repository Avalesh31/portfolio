# Планирование спринта 10

## 🎯 Цель спринта

По WSDL отдельного учебного сервиса разобраться, какие операции доступны для работы с владельцами и питомцами, какие данные они принимают и возвращают и куда направлять запрос.

## 📋 Состав работ

| Задача | Ожидаемый результат |
| --- | --- |
| Разобрать структуру WSDL | Краткое описание назначения разделов |
| Выписать операции MemberService и PetService | Перечень операций из portType |
| Восстановить контракты отдельных операций | Типы входных и выходных сообщений, отличия объекта от списка |
| Определить адреса сервисов | Endpoint для каждого сервиса |

## ✅ Критерии готовности

- [ ] Операции сгруппированы по сервисам.
- [ ] Для выбранных операций указаны входные и выходные данные.
- [ ] Для обоих сервисов указан адрес из WSDL.
