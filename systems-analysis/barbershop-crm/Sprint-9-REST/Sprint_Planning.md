# Планирование спринта 9

## 🎯 Цель спринта

Описать REST-взаимодействия для UC04 (регистрация клиента менеджером) и UC02 (формирование расписания мастера). Начать со шагов сценариев, затем определить вызовы и данные для каждого шага.

## 📋 Состав работ

| Задача | Ожидаемый результат |
| --- | --- |
| Уточнить шаги UC04 и UC02 | Обновлённые сценарии и список необходимых данных |
| Определить методы и справочники | Операции для регистрации и расписания, правила получения справочников |
| Расписать обмен в UC04 | Поля запросов и ответов, маппинг и варианты ошибок |
| Детализировать операции UC02 | Методы для работы с данными расписания мастера |

## ✅ Критерии готовности

- [ ] Для UC04 описаны проверка клиента по телефону, регистрация и отправка SMS.
- [ ] Для операций UC04 зафиксированы передаваемые поля и ошибки.
- [ ] Для UC02 перечислены вызовы и данные, нужные для формирования расписания.
