# Планирование Спринта 8

## 🎯 Цель спринта
*Как команда, мы хотим описать интеграции CRM с внешними системами (мастер‑системы, целевые системы, каналы обмена), чтобы обеспечить надёжный обмен данными и согласованность информации.*

## 📋 Бэклог спринта

### Must-have
| Задача | Story Points | Владелец |
|--------|--------------|----------|
| Определение мастер‑систем по ключевым доменам данных | 5 | [Андрей] |
| Описание целевых систем и сценариев использования данных | 5 | [Андрей] |
| Моделирование потоков данных между системами | 8 | [Андрей] |
| Составление словаря данных для интеграций | 8 | [Андрей] |

### Should-have
| Задача | Story Points | Владелец |
|--------|--------------|----------|
| Оценка объёмов и частоты обмена данными | 5 | [Андрей] |
| Определение требований к расписанию обмена и SLA | 3 | [Андрей] |

## ✅ Definition of Done

- [ ] Определены мастер‑системы и целевые системы для основных наборов данных
- [ ] Описаны ключевые сценарии интеграции и направления потоков данных
- [ ] Составлен словарь данных для интеграционного обмена
- [ ] Зафиксированы объёмы, частота обмена и основные требования к SLA
- [ ] Подготовлены артефакты, которые можно использовать как основу для REST/транспортного дизайна
