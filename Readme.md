## CRM для сети барбершопов

Учебный кейс School 21 о том, как перевести запись клиентов с телефона на онлайн-бронирование. В проекте описаны работа с расписанием мастеров, требования к CRM, модель данных и обмен с другими системами.

Я собрал материалы нескольких учебных модулей в один проект. В [README кейса](0_BRSP_Project/README.md) описаны спринты 1–8. В каждом спринте есть свой README и материалы по теме. Часть выполненных учебных модулей ещё не оформлена в спринты портфолио.
