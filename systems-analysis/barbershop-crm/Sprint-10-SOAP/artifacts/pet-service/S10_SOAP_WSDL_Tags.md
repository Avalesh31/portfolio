# Exercise 00. Назначение тегов первого уровня WSDL

| Тег | Назначение |
| --- | --- |
| `<definitions>` | Корневой элемент WSDL-документа: задает описание сервиса и пространства имен XML. |
| `<documentation>` | Содержит человекочитаемое описание назначения веб-сервиса. |
| `<types>` | Содержит определения типов данных, которые используются в сообщениях сервиса, обычно в виде XSD-схем. |
| `<message>` | Описывает абстрактные входные и выходные сообщения операций сервиса. |
| `<portType>` | Группирует операции сервиса и связывает каждую операцию с входным и выходным сообщением. |
| `<service>` | Описывает конкретный сервис и доступные точки подключения к нему. |
