# Планирование спринта 0

## 🎯 Цель спринта

Определить границы учебной задачи до работы с требованиями. Выделить части задачи и зафиксировать, откуда брать сведения и как называть основные понятия.

## 📋 Состав работ

| Задача | Ожидаемый результат |
| --- | --- |
| Разобрать задачу на составные части | Примеры декомпозиции и правила разбиения |
| Собрать источники по CRM и доставке | Два реестра источников |
| Выписать термины по каждой предметной области | Два отдельных глоссария |

## ✅ Критерии готовности

- [ ] По примерам можно проследить, как задача разбивается на части.
- [ ] Источники и термины разделены между CRM и доставкой.
- [ ] Глоссарий и реестр дают исходные данные для анализа стейкхолдеров и контекста в спринте 1.
