# Exercise 01. Методы раздела `<portType>`

## MemberService

| Операция | Назначение |
| --- | --- |
| `AddMember` | Добавляет нового члена клуба. |
| `GetAllMembers` | Возвращает список всех членов клуба. |
| `GetMemberByName` | Ищет и возвращает члена клуба по имени. |
| `UpdateMember` | Обновляет данные существующего члена клуба. |
| `DeleteMember` | Удаляет члена клуба по идентификатору. |

## PetService

| Операция | Назначение |
| --- | --- |
| `AddPet` | Добавляет нового питомца. |
| `GetAllPets` | Возвращает список всех питомцев. |
| `GetPetsByMemberId` | Возвращает питомцев, принадлежащих члену клуба с указанным идентификатором. |
| `UpdatePet` | Обновляет данные существующего питомца. |
| `DeletePet` | Удаляет питомца по идентификатору. |
