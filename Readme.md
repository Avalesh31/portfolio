# CRM для сети барбершопов

Учебный кейс по системному анализу, собранный Андреем Шемякиным на основе проектов School 21.

## Задача

Спроектировать работу с записями в сети барбершопов. В учебном сценарии администраторы принимают записи по телефону и вручную сверяют расписание. В целевом процессе клиент выбирает свободный слот и записывается онлайн, а сотрудники управляют расписанием в CRM.

## Мой вклад

Я собрал материалы нескольких учебных модулей в один кейс и выстроил их вокруг работы с расписанием и записями. В [папке проекта](0_BRSP_Project/) собраны артефакты от анализа процессов и требований до модели данных и спецификации интеграций.
