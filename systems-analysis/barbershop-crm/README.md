# CRM для сети барбершопов

Учебный кейс School 21. Задача — добавить онлайн-запись клиентов и дать сотрудникам возможность управлять расписанием мастеров в CRM. В кейсе описаны процессы, требования, данные и REST API.

Я собрал свои работы по системному анализу в тематические спринты. Нумерация соответствует исходной структуре кейса. Основной сценарий — работа с записями и расписанием сети барбершопов. Примеры по доставке и ветеринарному сервису отмечены отдельно. В каждом спринте есть описание результата, планирование, обзор и ссылки на файлы.
