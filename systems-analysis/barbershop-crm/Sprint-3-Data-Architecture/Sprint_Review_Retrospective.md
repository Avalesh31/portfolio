# Обзор и ретроспектива спринта 3

## 🏆 Результаты спринта

- Выделены сущности CRM и основные связи между ними.
- Подготовлены ER-диаграмма, словарь атрибутов и CRUD-матрица.

## 🔄 Ретроспектива

### Что получилось

- Словарь данных позволяет проверить, какие атрибуты нужны для работы с каждой сущностью.
- CRUD-матрица связывает модель данных с действиями в бизнес-процессах.

### Что можно улучшить

- Названия сущностей и атрибутов стоит привести к одной нотации в диаграмме, словаре и матрице.
- Для перехода к проектированию БД нужны более точные типы данных и обоснование решений по нормализации.

### План улучшений

- [ ] Сверить именование на примере сущностей, связанных со слотом записи.
- [ ] Дополнить словарь типами данных и вынести решения по нормализации в отдельные заметки.
