| 2 | `AddPetRequest` | input | `name` | Имя питомца. | `string` |  | да | Обязательное поле по умолчанию. |
| 3 | `AddPetRequest` | input | `kind` | Вид животного. | `string` |  | да | По условию: кот, собака, питон или хомяк. |

По `pet.wsdl` элемент `PetDataInput` не содержит поля `member_id`, хотя полная сущность `Pet` содержит это поле.
