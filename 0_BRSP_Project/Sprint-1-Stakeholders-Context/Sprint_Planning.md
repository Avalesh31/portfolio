# Планирование Спринта 1

## 🎯 Цель спринта
*Как команда, мы хотим понять, для кого мы строим систему и какие проблемы решаем, чтобы заложить фундамент для проектирования CRM.*

## 📋 Бэклог спринта

|--------|--------------|----------|
| Анализ стейкхолдеров | 5 | [Андрей] |
| Описание текущего состояния (As-Is) | 8 | [Андрей] |

### Should-have  
| Задача | Story Points | Владелец |

## ✅ Definition of Done

- [ ] Определены и задокументированы все ключевые группы стейкхолдеров
- [ ] Сформирован каталог стейкхолдеров с основными атрибутами
- [ ] Описано текущее состояние (As-Is) с выделением проблемных зон
- [ ] Сформулировано целевое видение (To-Be) для основных проблем
- [ ] Описаны основные потоки данных между стейкхолдерами и системой
