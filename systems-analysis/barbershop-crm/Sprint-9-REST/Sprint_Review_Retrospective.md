# Обзор и ретроспектива спринта 9

## 🏆 Результаты спринта

- Уточнены UC04 и UC02. Для обоих сценариев описаны необходимые REST-операции.
- Для UC04 отдельно описаны запросы и ответы, маппинг полей и обработка ошибок.

## 🔄 Ретроспектива

### Что получилось

- Операции выведены из шагов сценария. Например, при регистрации менеджер сначала проверяет клиента по телефону, а отправка SMS описана отдельным вызовом.
- Маппинг и ошибки вынесены в отдельные документы, поэтому проще сверить, какие данные передаются на каждом шаге.

### Что можно улучшить

- Операции, схемы сообщений и ответы с ошибками разнесены по нескольким документам. Их можно собрать в единый контракт.
- Операции стоит связать с требованиями по производительности и безопасности. Правила версионирования API ещё предстоит описать.

### План улучшений

- [ ] Собрать операции и схемы REST API в OpenAPI.
- [ ] Связать операции с функциональными требованиями и НФТ.
- [ ] Зафиксировать правила совместимости и версионирования.
