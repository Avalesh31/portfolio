# Обзор и ретроспектива спринта 5

## 🏆 Результаты спринта

- Описаны сущности со статусами. Жизненный цикл слота записи представлен диаграммой и текстовым описанием.
- Подготовлены CRUD для слота, расширенная CRUD-матрица и матрица прав доступа.

## 🔄 Ретроспектива

### Что получилось

- На примере слота видно, как связаны состояние объекта, разрешённое действие и роль пользователя.
- Диаграмма показывает переходы, а текстовое описание даёт условия их выполнения.

### Что можно улучшить

- Полезно явно связать переходы с шагами use case из спринта 4.
- Пограничные случаи, например попытку выполнить действие над слотом в неподходящем статусе, стоит вынести в отдельные проверки.

### План улучшений

- [ ] Пройти сценарий бронирования по диаграмме, CRUD и матрице доступа.
