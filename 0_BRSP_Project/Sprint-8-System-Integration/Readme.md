# Спринт 8: Системная интеграция (учебный модуль)

**Статус:** ✅ Завершен (как отдельный учебный модуль)  
**Цель:** Показать умение проектировать интеграцию между системами: выделять потоки данных, мастер‑системы, системы‑получатели, словарь данных и параметры обмена.

> Важно: этот спринт основан на учебном проекте `BSA14_SystemIntegration` и не относится напрямую к основному кейсу CRM барбершопа.  
> Он оформлен как отдельный модуль, демонстрирующий компетенции в области интеграции.

## 🎯 Логика модуля

Основан на `BSA14_SystemIntegration`:
- анализ потоков данных между системами;
- определение мастер‑систем и систем‑получателей;
- разработка словаря данных интеграционных потоков;
- описание сценариев интеграции;
- оценка объёмов, частоты и расписания обмена.

## 📊 Состав работ

- **ex00**: Выделение потоков данных (какие данные, откуда, куда и зачем).
- **ex01**: Определение мастер‑систем для входящих потоков.
- **ex02**: Определение систем‑получателей для исходящих потоков.
- **ex03**: Построение словаря данных по каждому потоку.
- **ex04**: Описание сценариев интеграции.
- **ex05**: Оценка объёмов данных и количества сообщений.
- **ex06**: Определение частоты и расписания обмена, базовые SLA.

## 🔗 Бизнес-ценность

Такой модуль позволяет:
- системно мыслить об интеграциях (кто за что отвечает, какие данные “чьи”);
- уменьшить риск рассинхронизации данных между системами;
- заранее оценивать нагрузку на интеграционную шину/каналы обмена;
- формулировать требования к SLA и расписанию обмена.
