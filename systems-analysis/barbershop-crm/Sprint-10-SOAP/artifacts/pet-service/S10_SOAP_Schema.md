# Exercise 02. Раздел `<schema>`

| Элемент или атрибут | Назначение |
| --- | --- |
| `<element>` | Определяет XML-элемент, который может находиться в сообщении или внутри другого структурного элемента. |
| Атрибут `type` элемента `<element>` | Указывает тип данных элемента: простой XSD-тип или пользовательский комплексный тип. |
| `<complexType>` | Определяет структурный тип данных, который содержит вложенные элементы. |
| `minOccurs` | Задает минимальное количество появлений элемента. |
| `maxOccurs` | Задает максимальное количество появлений элемента. |
| `<sequence>` | Требует, чтобы вложенные элементы шли в XML-сообщении в указанном порядке. |
| Не указан `minOccurs` | Значение по умолчанию равно `1`, поэтому элемент обязателен. |
| Не указан `maxOccurs` | Значение по умолчанию равно `1`, поэтому элемент может встретиться не более одного раза. |
| `maxOccurs="unbounded"` | Элемент может повторяться неограниченное количество раз. |
| Признак обязательности | Элемент обязателен, если `minOccurs` не указан или больше `0`; элемент необязателен, если `minOccurs="0"`. |
