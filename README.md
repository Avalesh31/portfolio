## Проекты

### Системный анализ · CRM для сети барбершопов

Учебный кейс School 21. Задача — добавить онлайн-запись клиентов и дать сотрудникам возможность управлять расписанием мастеров в CRM.

Я объединил материалы нескольких учебных модулей в один кейс и разложил работу по спринтам. В кейсе описаны бизнес-процессы, требования к записи и расписанию, модель данных и обмен с другими системами. Отдельный спринт посвящён приоритизации требований и планированию релизов.
